# SportyBet Arena - App

A sports betting community app founded 2021 in Johannesburg.

## Features - 6 Pages

1. Home - Bet on favorite matches, featured odds
2. About Us - History, Mission, Vision, Business Goal (100k users by 2027)
3. Overview - Dashboard with Users 100k, Fees R204k, Active Today 4,200
4. Individual Match - Kaizer Chiefs vs Pirates, Odds, Comments
5. Calculate Fees - ZAR Calculator with 10% fee capped R50 + 15% VAT
6. Contact Us - Form + Address 101 Sporty Ave JHB 2001

## Tech

Expo, React Native, TypeScript, Expo Router

## How to Run

npm install
npx expo start --web --port 8083
